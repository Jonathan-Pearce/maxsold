# References Directory

This directory contains reference materials, data dictionaries, manuals, and other explanatory materials.

## Purpose

Store reference materials that support understanding and using the project:
- Data dictionaries
- API documentation
- Domain knowledge resources
- External paper citations
- Manuals and guides
- Glossaries

## Examples

- `data_dictionary.md` - Definitions of all data fields
- `api_documentation.md` - MaxSold API documentation
- `auction_business_rules.md` - Business rules for auction bidding
- `glossary.md` - Terminology used in the project

## Best Practices

1. **Keep it organized**: Use subdirectories for different types of references
2. **Use markdown**: Easy to read and version control
3. **Link from code**: Reference these docs in your code comments
4. **Keep it up to date**: Update when domain knowledge changes
